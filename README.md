# Covid-19 Data Analysis

This project analyzes COVID-19 data in India, including case trends and vaccination statistics.

## 📁 Files in This Repository

- `Covid_Data_Analysis_Project.ipynb` - Main Jupyter Notebook with data cleaning, visualization, and analysis.
- `covid_19_india.csv` - Dataset containing daily COVID-19 case data for India.
- `covid_vaccine_statewise.csv` - Dataset showing vaccination progress across Indian states.

## 🔍 Project Objectives

- Explore trends in daily and cumulative COVID-19 cases.
- Analyze state-wise case distribution and death rates.
- Study the progress of the vaccination drive in India.
- Visualize the findings using Python libraries like Matplotlib and Seaborn.
